# C# File Operations

A C# console application demonstrating file operations using the `System.IO` namespace.

## 📌 About the Project

This project demonstrates how to work with files in C#, including creating, reading, writing, copying, moving, deleting files, and retrieving file information.

## 🚀 Features

- **File Existence Check** — Check whether a file exists using `File.Exists()`.
- **File Creation** — Create a new file using `File.Create()`.
- **Read File Content** — Read the entire file using `File.ReadAllText()`.
- **Read Lines** — Read individual lines using `File.ReadAllLines()`.
- **Count Characters** — Count characters in a string.
- **Write to File** — Write text using `File.WriteAllText()`.
- **Append Text** — Add text to an existing file using `File.AppendAllText()`.
- **File Attributes** — Retrieve file attributes using `File.GetAttributes()`.
- **File Timestamps** — Get creation, last access, and last modification times.
- **Copy Files** — Copy files using `File.Copy()`.
- **Move and Rename Files** — Move or rename files using `File.Move()`.
- **Delete Files** — Delete files using `File.Delete()`.
